# Frontend de OpenBlind

Aplicación construida con Next.js, React, TypeScript y Tailwind CSS.

## Estructura

```text
src/app/         Rutas, layouts y estilos globales de Next.js.
src/components/  Elementos visuales reutilizables.
src/features/    Código agrupado por funcionalidad de negocio.
src/hooks/       Hooks, incluido el futuro uso de Web Speech API.
src/lib/         Clientes de API y utilidades.
src/types/       Tipos TypeScript compartidos.
public/      Recursos estáticos.
```

## Inicio local

```bash
npm install
npm run dev
```
